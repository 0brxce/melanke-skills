# defi-builder-skills

A marketplace of [Claude Code](https://claude.com/claude-code) skills for designing and building DeFi protocols from scratch.

[![Featured in Web3 Security Tools Hub](https://img.shields.io/badge/Featured%20in-Web3%20Security%20Tools%20Hub-blue)](https://github.com/pashov/ai-web3-security#solidity--evm)

## Add this marketplace

```
/plugin marketplace add melanke/defi-builder-skills
```

## Skills

| Plugin | Description |
|---|---|
| [`defi-protocol-discovery`](plugins/defi-protocol-discovery/README.md) | From raw idea to go/no-go decision — lean canvas, analogue analysis, economic stress-testing, and assumption mapping. |
| [`defi-spec-driven`](plugins/defi-spec-driven/README.md) | Six-phase DeFi protocol specification before any Solidity, then per-function implementation tracked against the spec. |

## Install a skill

```
/plugin install defi-protocol-discovery@defi-builder-skills
/plugin install defi-spec-driven@defi-builder-skills
```
